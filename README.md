# Rabble & Rouse

Website for *Rabble & Rouse with Katie Martell*, a web series of real conversations with real people.

Static pages: `index.html` (home) and `episode-1.html` (episode details, credits, signup), plus the `media/` folder (season preview, Episode 1 first look, set photos, host cutout). Open it from any static host; no build step.

Libraries load from jsDelivr: GSAP + ScrollTrigger, Lenis, and Three.js (curtain loader and footer sign).
